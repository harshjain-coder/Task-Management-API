SMART TASK MANAGEMENT - FULL STACK

A polished task workspace with JWT auth, Gemini AI task creation, Kanban, Calendar, dependencies, templates, subtasks, reminders and productivity insights.

SETUP
1. Open this folder in VS Code.
2. Create/activate a virtual environment.
3. Run: python -m pip install -r requirements.txt
4. Copy .env.example to .env
5. Add your Gemini API key to .env: GEMINI_API_KEY=your_key
6. Run: python manage.py migrate
7. Run: python manage.py runserver
8. Open frontend/index.html with VS Code Live Server.

IMPORTANT
- Restart Django after changing .env.
- Never put GEMINI_API_KEY in frontend/script.js or GitHub.
- AI features require a valid Gemini API key and API access/quota.
